📂 Task Overview
-------------------------------------------
This repository contains three key tasks showcasing data analytics and machine learning workflows:
1. CSV File Debugging & Jupyter Notebook Execution
2. Exploratory Data Analysis (EDA) on Social Media Dataset
3. Sales Prediction Model using Linear Regression & Random Forest

The tasks demonstrate practical problem-solving, data exploration, and predictive modeling skills using Python, Pandas, NumPy, Matplotlib, Seaborn, and Scikit-learn.

-------------------------------------------
🛠️ Task 1: CSV Debugging & Jupyter Notebook Execution
-------------------------------------------
Objective:
- Resolve file path errors and ensure smooth execution of Jupyter Notebook.

Steps Taken:
- Verified dataset location and corrected relative/absolute paths.
- Implemented chunk loading for large CSVs to optimize memory usage.
- Ensured reproducibility by adding clear comments and structured code cells.

Outcome:
- Stable environment setup for further analysis.

-------------------------------------------
📊 Task 2: Exploratory Data Analysis (EDA) on Social Media Dataset
-------------------------------------------
Objective:
- Perform EDA on a large dataset to uncover trends and insights.

Steps Taken:
- Loaded dataset in chunks using pandas.read_csv(chunksize=...).
- Cleaned missing values and standardized column formats.
- Generated descriptive statistics and visualizations (distribution plots, correlation heatmaps).
- Identified key behavioral patterns and anomalies in user activity.

Outcome:
- Comprehensive understanding of dataset structure and trends.

-------------------------------------------
🤖 Task 3: Sales Prediction Model
-------------------------------------------
Objective:
- Build predictive models to forecast sales.

Steps Taken:
- Preprocessed data (feature selection, encoding categorical variables, scaling).
- Implemented Linear Regression for baseline performance.
- Applied Random Forest Regressor for improved accuracy and robustness.
- Evaluated models using RMSE, MAE, and R² metrics.

Outcome:
- Random Forest achieved better predictive performance, highlighting non-linear relationships in sales data.

-------------------------------------------
📦 Requirements
-------------------------------------------
- Python 3.8+
- Libraries: pandas, numpy, matplotlib, seaborn, scikit-learn, jupyter

Install dependencies:
    pip install -r requirements.txt

-------------------------------------------
🚀 How to Run
-------------------------------------------
1. Clone the repository.
2. Open Jupyter Notebook:
       jupyter notebook
3. Navigate to the respective task notebooks:
   - Task1_CSV_Debugging.ipynb
   - Task2_EDA_SocialMedia.ipynb
   - Task3_SalesPrediction.ipynb

-------------------------------------------
📈 Results & Insights
-------------------------------------------
- Debugging ensured smooth workflow for large datasets.
- EDA revealed meaningful patterns in social media engagement.
- Random Forest outperformed Linear Regression in predicting sales, making it the recommended model for deployment.
